ZDZAS-MCP is een krachtige MCP-server die fungeert als een centrale integratielaag tussen Zendesk, Jira, Confluence en een AI-agent.
Het project breidt de standaard Zendesk AI-functionaliteit uit met tooling die:
tickets analyseert en clustert
concept- en finale kennisbankartikelen genereert
Jira-issues ophaalt voor geparkeerde of technische tickets
Confluence-documentatie doorzoekt voor productinformatie
responses van de AI verrijkt met real-time interne data
De server werkt met veilige API-authenticatie via environment variables en is modulair opgezet zodat nieuwe tools eenvoudig toegevoegd kunnen worden.
Het doel: supportteams ontlasten door AI toegang te geven tot alle relevante informatie, waardoor tickets sneller, consistenter en nauwkeuriger worden afgehandeld.
